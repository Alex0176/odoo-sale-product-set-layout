1. *Sales → Products → Product Sets*: create a set, choose *Insert as section* and
   the *Print mode*, add the lines. Mark correction lines as *Hidden* and give them
   a *Fixed price* if needed.
2. In a quotation click *Add set*, choose the set and the quantity. Section name and
   print mode can be adjusted before the set is added.
3. Single order or invoice lines can be hidden with the column *Hidden in report*.

**Note:** hidden lines are part of the totals but invisible on the document. Check
whether this is compatible with the invoicing rules of your country (e.g. the
required description of the supplied goods/services).
